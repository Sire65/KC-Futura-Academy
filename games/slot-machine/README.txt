KC EINARMIGER BANDIT

Start:
1. ZIP entpacken.
2. index.html doppelt anklicken.
3. Läuft ohne Installation in Chrome, Edge, Firefox und auf Tablets.

Funktionen:
- 3 Walzen mit Köcheclub-Symbolen
- Startknopf und Hebel
- Punkte, Spiele, Gewinne, Jackpots
- Risiko Rot/Schwarz
- Ton Ein/Aus
- lokale Speicherung im Browser
- Tablet-optimierte Bedienung

Hinweis:
Reines Unterhaltungsspiel ohne Echtgeld.
